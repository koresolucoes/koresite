# Kore Soluções — site institucional

Projeto de site da Kore Soluções, com páginas de serviços, cursos e artigos sobre automação, n8n, APIs e integrações.

O código usa Next.js com App Router e TypeScript. Para conhecer a estrutura, comece pelas rotas em `src/app`, incluindo `blog`, `cursos` e `servicos`.

## Rodar localmente

```bash
npm ci
npm run dev
```

Abra [localhost:3000](http://localhost:3000).
